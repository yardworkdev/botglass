botglass

See your site exactly as AI crawlers see it.

AI crawlers fetch your HTML and never run JavaScript. A React, Next.js or Vue page can look finished to you and near-empty to GPTBot, ClaudeBot and PerplexityBot. botglass fetches the same URL as a normal browser and as eight crawlers, compares the text each one actually receives, checks robots.txt per bot, and prints one verdict per crawler.

No account, no API key, no dashboard, no telemetry. One command, plain HTTP.

Run it

npm install -g https://github.com/yardworkdev/botglass/releases/download/v0.4.3/botglass-0.4.3.tgz
botglass https://example.com

Node 20+. The built package installs without the npm registry; the README has the no-install form and the MCP setup.
